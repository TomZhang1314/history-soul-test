# 测测你的灵魂对应哪位中国历史人物

## 打开方式

解压后，双击 `index.html` 即可在现代浏览器中运行。HTML、CSS、JavaScript 均在同一文件中，没有外部字体、图片、接口或框架，无需安装、无需联网、无需后端。

手机上请用支持本地 HTML 的浏览器打开；微信/小红书附件预览可能不执行 JavaScript。如要发送可点击的测试链接，可把 `index.html` 上传到任意静态网站托管服务。本包不包含线上部署。

## 功能

- 40道生活化单选题，14个人物结果，覆盖谋士、帝王、文人、侠客、诗人、将领、隐士。
- 首页、逐题选择、进度、上题修改、自动评分、结果页、重测确认。
- 尝试在本机自动保存进度。关闭存储不会影响当前答题。
- 适配手机与电脑，键盘选择、焦点提示、减少动画偏好。
- 完整结果适合截图，按钮还可生成1080×1580 PNG精简分享卡。
- 浏览器可能把图片下载为文件；移动端若无下载，可长按预览图保存。

## 评分规则

五维依次是：独处/联结、共情/推演、从容/进取、务实/想象、自由/秩序。

每维8题，各题四选项贡献 -3、-1、+1、+3 分，展示位置轮换。单维总分范围 -24 至24，按 `(总分+24)/48×100` 映射到0–100。

14个人物各有一个五维文化原型向量，使用五维等权均方距离匹配最接近的人物；距离完全相同时依固定人物顺序决定，保证相同答案稳定得到相同结果。第二名与第一名的均方根距离差小于5时显示「双生气质」。这个阈值是产品展示规则，不是统计置信区间。

结果理由优先采用：用户与原型同侧、且偏离中点至少8分的两个最强维度。倾向较均衡时使用均衡型说明，不编造强烈特征。图上的位置是答题倾向，不是人口百分位、诊断得分或匹配概率。

人物是文化印象的艺术化提炼，专属文案均为原创，不冒充古人名言。类别用于趣味分组（同一人物可能有多重身份）。测试未经专业心理测量验证，不用于评估心理健康、能力高低或作重要决策。

## 修改与验证

`index.html` 中：`RAW` 为题库；`AXES` 为维度；`PEOPLE` 为人物与文案；`score` 为纯评分函数；`createPoster` 为分享图生成。

如已安装 Node.js，运行 `node verify.cjs`。它验证语法、题目结构、边界、每个人物可达、50000组模拟、完整流程、改答与续答等，并输出 `validation.json`。该脚本使用轻量 DOM 替身验证程序流程，不能代替真实浏览器渲染测试。

隐私：没有联网请求、登录、追踪或上传；本机存储键为 `jianji-history-v1`。重新测试会清除当前已答内容。共享设备上建议完成后点击重新测试，或清除浏览器站点数据。
